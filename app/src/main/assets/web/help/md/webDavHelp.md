# WebDav 备份与同步教程

阅读通过 WebDav 协议实现三项云端能力：**备份/恢复**（App 设置与书架）、**阅读进度同步**、**书籍同步**（远程导入与上传副本）。任何支持 WebDav 的网盘或自建服务都可以使用（坚果云、Alist、群晖、InfiniCloud 等）。

### 一、配置步骤（三步）

1. **服务器地址**：填写 WebDav 服务的根地址即可（例如坚果云为 `https://dav.jianguoyun.com/dav/`），不必精确到子目录。自建服务注意带上端口（如 `https://dav.example.com:6789/`）。
2. **账号 / 密码**：填写 WebDav 服务的账号与密码。坚果云需要在网页端「账户信息 → 安全选项 → 第三方管理」添加应用获取专用密码，不能使用登录密码。
3. **选择目录**：点击「选择目录」，App 会登录服务器浏览目录，并**自动定位到 legado 目录**（两级范围内探测）；也可以手动浏览（点 `..` 返回上级）后点「使用此目录」。

确认后 App 会在所选目录下自动创建并校验三个子目录，全部就绪后提示「WebDav已连接」：

* `bookProgress/` —— 阅读进度（JSON，按 `书名_作者.json` 命名）
* `books/` —— 书籍交换目录（远程书籍页默认浏览这里）
* `background/` —— 阅读背景图片

> 说明：新版通过「选择目录」确定工作路径，不再需要手动拼接子文件夹；旧版本的「子文件夹」设置项已由该功能取代（旧配置仍兼容，重新选择一次目录即完成迁移）。地址栏支持直接粘贴含中文或空格的路径，也支持 URL 编码形式。

### 二、目录结构与同步机制

* **阅读进度**：默认开启（设置中「同步阅读进度」开关）。退出阅读界面时上传，翻页后空闲 5 分钟自动上传，App 启动时拉取云端较新的进度——重装或换机后重新导入同名书籍即可自动恢复阅读位置。
* **书籍同步**：把 txt/epub 等文件放入 `books/` 目录（网盘客户端批量上传或 App 内上传均可），在 我的/书架右上角菜单/远程书籍 中浏览并「放入书架」。
* **备份**：我的-备份与恢复-备份 手动触发；设置好 WebDav 后每次退出 App 也会自动备份，同一天的备份相互覆盖。

### 三、恢复

* 入口：我的-备份与恢复-恢复，从云端备份列表中选择文件；启动 App 时检测到云端备份比本地新，也会弹窗询问是否恢复。
* 恢复会覆盖当前 App 的设置与书架数据，请谨慎操作。

### 四、常见问题

* **提示「WebDav配置失败」**：检查地址是否含 `https://` 与正确端口、账号密码是否正确；详细原因见本页右上角 "**⁝**" > 日志。
* **进度没有恢复**：确认书籍与云端进度记录同名（按 `书名_作者.json` 匹配），且启动时网络可用；「同步阅读进度」开关需为开启状态。
* **更换密码**：在设置中更新密码即可，新密码验证成功前旧的可用连接会保留。
* **远程书籍页列表为空**：确认书籍在所选目录的 `books/` 子目录下；远程书籍页右上角 "**⁝**" > 服务器配置 可切换或添加其他 WebDAV 服务器。
